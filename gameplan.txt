You are an elite web game architect and senior frontend engineer. Your task is to design and write the complete foundational architecture for a polished, highly addictive single-file HTML5/JavaScript incremental tycoon game called "Paw-Print Factory Tycoon". 

The game combines the cozy aesthetic of modern web games with the nostalgic, tactile progression of classic Roblox tycoons (e.g., dropper-to-conveyor pipelines, physical floor buy-buttons, and upgraders).

### 1. Technical Constraints & Architecture
- Single File: Everything must be contained in ONE production-ready HTML file (embedded Tailwind CSS via CDN, Google Fonts, Lucide icons, and vanilla JavaScript).
- Zero External Assets: All graphics must be procedurally rendered on HTML5 Canvas or via crisp vector CSS/SVG. All sound effects must be synthesized programmatically using the browser's native Web Audio API (zero external audio file dependencies).
- Modularity: The JavaScript code must be cleanly separated into clearly commented sections:
  1. CONFIG & BALANCING (Cost scaling formulas, item data, upgrade tiers)
  2. GAME STATE (Resources, owned buttons, active machines, player coordinates)
  3. AUDIO ENGINE (Procedural sound effects: cash collection, buy button chime, upgrader laser, error buzz)
  4. INPUT & PLAYER CONTROLLER (WASD/Arrow keys for moving a custom 2D furry avatar around the factory floor)
  5. FACTORY PHYSICS & PIPELINE (Conveyor belt movement, item dropping, upgrader multiplier logic, collector furnace)
  6. RENDERER (60 FPS canvas loop rendering floor tiles, animated belts, glowing buy buttons, floating text popups, and moving items)
  7. SAVE / LOAD SYSTEM (localStorage persistence with automatic interval saving, plus Export/Import base64 string backup buttons)
  8. UI OVERLAY (Top HUD for Cash, Gems, Rebirths, and interactive modals for upgrades/settings)

### 2. Core Gameplay Mechanics to Implement in Phase 1
- Player Movement: The player avatar walks around a 2D factory plot.
- Glowing Floor Buy-Buttons: Glowing pads on the canvas floor. When the player steps on them and has enough cash, the button triggers a "cha-ching" sound, subtracts the cost, pops the structure (Dropper, Conveyor, Upgrader) into existence with a scale animation, and unlocks the next pad in sequence.
- Resource Pipeline:
  - Droppers spawn physical cubes onto Conveyor Belts at regular intervals.
  - Conveyor belts animate arrows and push items forward.
  - Upgrader gates flash and double/triple the item value when passed through.
  - Collector Furnace at the end of the line cashes out items into the player's bank with floating "+$X" text.
- Starter Progression Line: Include at least 12 sequential unlockable buttons starting from Entrance / Cash Collector -> Dropper 1 -> Conveyor Run -> Upgrader Gate -> Dropper 2 -> Walls & Decor -> Advanced Smelter.

- Write clean, fully working, syntactically correct code without placeholder comments like "// TODO: implement later". Every function must be fully fleshed out so the game is immediately playable upon opening the HTML file in a browser.
- Include smooth CSS styling for all UI elements outside the canvas (menus, notifications, settings, save/load modals).
